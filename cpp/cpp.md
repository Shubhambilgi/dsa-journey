## Problem-Solving Workflow

For each problem, I aim to:

1. Understand the problem and its constraints.
2. Work out the approach before coding.
3. Implement the solution in C++.
4. Test normal cases and edge cases.
5. Analyse time and space complexity.
6. Improve the solution when possible.
