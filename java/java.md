## Problem-Solving Workflow

For each problem, I aim to:

1. Understand the problem and its constraints.
2. Plan the approach before writing code.
3. Implement the solution in Java.
4. Test normal cases and edge cases.
5. Analyse time and space complexity.
6. Refactor the code when improvements are possible.

## Code Organisation

Use descriptive filenames and Java class names, for example:

```text
arrays/
├── ReverseArray.java
├── FindLargestElement.java
└── SecondLargestElement.java
```

Java public class names should match their filenames.
